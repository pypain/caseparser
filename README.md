# Caseparser — Danger Zone Case

Локальное приложение для сравнения цен CS2 Danger Zone Case и учета чужих кейсов.
Python 3.9+, SQLite, без сторонних зависимостей.

## Запуск на своем компьютере

Установи Python 3.9 или новее и Git. Затем в терминале:

```sh
git clone https://github.com/pypain/caseparser.git
cd caseparser
python3 app.py
```

На Windows последнюю команду замени на `py -3 app.py` (или `python app.py`).
Открой в браузере `http://127.0.0.1:8000`. Автосбор запускается вместе с приложением;
терминал должен оставаться открытым. Остановка — Ctrl+C. Устанавливать пакеты через pip не нужно.
При первом запуске локальная база создается автоматически; реальные цены появляются
после запросов к доступным источникам. Ошибки доступа видны в разделе «Автосбор».

В cloud-среде используй существующий checkout: `cd /workspace/caseparser && python3 app.py`.

В обычной локальной среде интерфейс доступен на порту 8000, только на loopback.
Есть парольный вход для одного владельца кабинета; разделения на нескольких пользователей нет.
В cloud onboarding веб-превью не предоставляется.

## Интерфейс и пароль

Отдельные страницы: `/prices`, `/collection`, `/inventory`, `/history`, `/markets`.
Боковая навигация, светлая и темная темы, адаптация для телефона.
Автоматические цены видны и без настроек комиссий, но расчет выручки в таком случае не показывается.

Для защищенного локального запуска (Linux/macOS):

```sh
mkdir -p .data
umask 077
python3 auth.py > .data/password.hash
CASEPARSER_PASSWORD_HASH="$(cat .data/password.hash)" python3 app.py
```

`auth.py` запрашивает пароль скрыто. В файле только salted PBKDF2-хеш; пароли не
встраиваются в исходники. Не добавляй `.data` в Git. Без `CASEPARSER_PASSWORD_HASH`
сохраняется локальный режим без входа. Публичный адрес запуска требует одновременно
парольного хеша, TLS-сертификата и `CASEPARSER_COOKIE_SECURE=1`; иначе запуск отклоняется.
Сессия на 12 часов: HttpOnly, SameSite=Strict, Secure при HTTPS. После пяти неудачных
входов — ограничение на 15 минут. Выход удаляет серверную сессию.

## Отдельное размещение на сервере

Подготовлен `deploy/install.sh` для **первой** установки на Linux с systemd и Python 3.9+.
Сервер должен иметь openssl, curl и стандартные административные утилиты.
Сначала выполни на сервере:

```sh
git clone https://github.com/pypain/caseparser.git /root/caseparser-source
cd /root/caseparser-source
bash deploy/install.sh
```

Установщик запросит пароль приложения; введи выбранный пароль. Он создает отдельного
пользователя и сервис `caseparser`, приложение в `/opt/caseparser`, данные в
`/var/lib/caseparser`, приватную конфигурацию в `/etc/caseparser`.
По умолчанию адрес — `https://107.161.175.52:8443`. Порт проверяется до установки;
если занят или каталоги/сервис уже существуют, установка остановится без перезаписи.
Иной порт/IP: `CASEPARSER_DEPLOY_PORT=9443 CASEPARSER_DEPLOY_IP=107.161.175.52 bash deploy/install.sh`.
Скрипт не меняет nginx, другие сайты, SSH и правила firewall; сервис автоматически
запускается после перезагрузки. Порт нужно отдельно разрешить в firewall хостинга.

Создается **самоподписанный TLS-сертификат**: браузер покажет предупреждение.
Перед доверием сверь SHA-256 fingerprint с выводом установщика; для обычного
доверенного HTTPS нужен домен и доверенный сертификат, либо отдельная процедура выпуска.
Проверки самого установщика используют созданный сертификат без отключения TLS-верификации.

```sh
systemctl status caseparser
journalctl -u caseparser -n 50
systemctl stop caseparser  # Остановить только это приложение
```

Установка на целевой сервер еще не выполнена: SSH-доступ из cloud-среды был недоступен.
Интеграционное тестирование установщика на этом сервере не проведено.

## Что работает

- Каталог 17 площадок-кандидатов, исключение площадок из продаж.
- Ручные котировки и атомарный CSV-импорт; время, источник, способ вывода, комиссии.
- Раздельное сравнение мгновенных продаж и цен выставления, история и график.
- Цены старше суток, Steam, исключенные площадки и непроверенные способы вывода не рекомендуются.
- Партии по владельцам, завершенные продажи, фактические переводы, остатки и долг.
- 15% от фактически полученных после вывода денег — тебе, оставшаяся сумма — владельцу.
  Расчет в копейках, доля округляется до копейки, остаток достается владельцу.
- Защита от продажи лишних кейсов и выплат сверх долга, включая одновременные запросы.

Все суммы в RUB. Криптовалютные выплаты записываются в рублевом эквиваленте после
фактической конвертации. Не складывай USDT и рубли без пересчета. Прогноз:
`(цена × количество × (1 − комиссия продажи) × (1 − комиссия вывода)) − фиксированная комиссия`.
Фиксированная комиссия применяется один раз за весь вывод; условия конкретного сайта могут отличаться.
Это оценка по введенным данным: объем заявок, сроки продажи, лимиты вывода и проскальзывание не учитываются.

## Автоматический сбор

`python3 app.py` автоматически запускает фоновый сборщик вместе с интерфейсом.
Первый запрос выполняется при запуске, следующие — каждые 15 минут. Кнопка
«Проверить обновление» будит сборщик, сохраняя интервалы запросов. Срок следующей
попытки хранится в SQLite: перезапуск и несколько процессов не обходят ограничение.
При ошибках пауза увеличивается до 6 часов. Последняя успешная цена остается с ее
исходным временем; ошибок с фиктивной ценой 0 нет.

Подключены публичные API:

| Площадка | Данные | Проверка в текущей среде |
| --- | --- | --- |
| Market.CSGO | Цена предложения Danger Zone Case в RUB | Живой запрос успешен |
| Steam Community Market | Минимальная цена предложения в RUB | Живой запрос успешен; без денежного вывода |
| Skinport | Минимальная цена предложения в USD | Источник ответил HTTP 403; живой результат не подтвержден |
| CSFloat | Минимальная цена buy_now в USD, API в центах | HTTP 403; живой результат не подтвержден |
| Waxpeer | Минимальная цена в USD, API в тысячных USD | Живой запрос успешен |
| Tradeit | Цена магазина storePrice в USD, API в центах | API доступен; для Danger Zone Case предложений нет, ключ от кейса исключается |

DMarket отключен: старый API возвращает HTTP 410, новый требует авторизацию,
его формат цен пока не проверен. Полная выгрузка LIS-SKINS превышает 1 ГБ;
автоматически скачивать ее каждые 15 минут нецелесообразно. Остальные
неподключенные источники явно отмечены в интерфейсе.

Используются только бесплатные источники; платный агрегатор не подключен.
Для CSFloat можно передать бесплатный ключ аккаунта в `CSFLOAT_API_KEY`, если API
потребует авторизацию. Значения ключей нельзя отправлять в чат или добавлять в Git.
В публичном запуске переменную добавляют в защищенный EnvironmentFile сервиса
через редактор на сервере (не через команду с ключом в аргументах), затем перезапускают
только `caseparser`. Ответ HTTP 401 отображается как необходимость авторизации;
HTTP 403 или ошибка прокси не подменяются диагнозом «нет ключа».
Нужные домены: `market.csgo.com`, `steamcommunity.com`, `api.skinport.com`,
`csfloat.com`, `api.waxpeer.com`, `tradeit.gg`.
HTTPS-проверка сертификатов включена; обход защиты сайтов не используется.
Автосбор добавляет каждую успешную котировку в историю и график. График фильтруется
по валюте, рубли и доллары не смешиваются. Отмеченное время — получение API-ответа,
а не подтвержденное время обновления цены на стороне площадки.

Цены хранятся независимо от условий вывода. В интерфейсе задай комиссии, способ
вывода и при необходимости курс USD/RUB один раз для каждой площадки. После этого
расчет выручки использует свежую автоматическую цену. Курс конвертации и комиссии
обновляются вручную; до их подтверждения источник не включается в рекомендации.
У каждой площадки хранится один активный набор условий вывода. Для сравнения
нескольких способов по одной площадке можно добавлять ручные котировки.

Отдельный запуск без веб-интерфейса:

```sh
python3 collect.py --once  # Один цикл; exit 1, если источник в состоянии ошибки
python3 collect.py         # Постоянное обновление; Ctrl+C для остановки
```

Не нужно запускать отдельный сборщик вместе с app.py. Исключение площадки запрещает
ее рекомендации и продажи, но сохраняет сбор цен для наблюдения.

## Ограничения

Каталог 17 площадок не является проверенным списком всех популярных сервисов.
Автосбор реализован для шести источников выше, остальные 11 пока доступны только
для ручных котировок и CSV. Их интеграции не реализованы; возможность получения
цен нельзя заключить из наличия сайта в каталоге. Все 17 площадок теперь видны
в сравнении: цена, если она получена, либо явная причина отсутствия данных.
`sources.py` содержит реестр покрытия; счетчик каталога не выдается за количество
живых источников. Waxpeer и Tradeit проверены на живых ответах;
CSFloat проверен на тестовых данных, живой доступ вернул 403. Skinport также
требует разрешения проблемы доступа со стороны сервиса; повтор после изменения доступа произойдет автоматически по расписанию.
Доступность вывода в РФ, комиссии, лимиты, объем спроса и актуальность сайтов
требуют отдельной проверки. Нет торговли, подключения Steam, кошельков или отправки
денег. Нет статусов выставления, отмены/редактирования операций; вводятся только
завершенные продажи и выплаты.

## Обновление установленного сервера

Не запускай установщик повторно для обновления: он защищает существующие каталоги.
Выполни на сервере:

```sh
cd /root/caseparser-source
git pull --ff-only
bash deploy/update.sh
```

Обновляется только сервис `caseparser`. База, пароль и TLS сохраняются; перед
заменой кода создается SQLite backup. При неудачной HTTPS-проверке возвращается
старый код. Другие сайты и nginx не меняются. Скрипт прошел проверку синтаксиса,
но не выполнялся на целевом сервере из этой cloud-среды.

Диагностика доступности из сети сервера без записи в базу:

```sh
python3 diagnose_sources.py
```

Скрипт проверяет шесть ценовых API и доступность сайтов остальных площадок;
не выводит ключи и приватные ответы. Успешный ответ сайта без адаптера не означает,
что сбор цен с него готов.

CSV: `market,price_rub,sale_fee,withdrawal_fee,fixed_fee_rub,method,verified,kind,observed_at,source`.
Названия площадок как в каталоге; `verified`: 0/1, `kind`: instant/listing.
`observed_at`: ISO 8601 с часовым поясом; если пусто — время импорта.
`source`: ссылка/описание источника и использованного валютного курса.

## Проверка и хранение

```sh
python3 -m unittest discover -s tests -v
```

База: `.data/cases.sqlite3`, путь можно переопределить `CASEPARSER_DB`, порт — `PORT`.
Храни резервную копию базы вне checkout; для согласованной копии используй SQLite backup
либо копируй файл после остановки сервера. Данные не отправляются внешним сервисам.
Каждый cloud task уже изолирован; используй существующий checkout, отдельный worktree не нужен.
