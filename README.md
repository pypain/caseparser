# Caseparser — Danger Zone Case

Локальное приложение для сравнения цен CS2 Danger Zone Case и учета чужих кейсов.
Python 3.12+, SQLite, без сторонних зависимостей.

## Запуск на своем компьютере

Установи Python 3.12 или новее и Git. Затем в терминале:

```sh
git clone https://github.com/pypain/caseparser.git
cd caseparser
python3 app.py
```

На Windows последнюю команду замени на `py -3 app.py` (или `python app.py`).
Открой в браузере `http://127.0.0.1:8000`. Автосбор запускается вместе с приложением;
терминал должен оставаться открытым. Остановка — Ctrl+C. Устанавливать пакеты через pip не нужно.
При первом запуске локальная база создается автоматически; реальные цены появляются
после запросов к доступным источникам. Ошибки доступа видны в разделе «Автосбор».

В cloud-среде используй существующий checkout: `cd /workspace/caseparser && python3 app.py`.

В обычной локальной среде интерфейс доступен на порту 8000, только на loopback.
Сервер не предназначен для публичного размещения: нет авторизации и разделения пользователей.
В cloud onboarding веб-превью не предоставляется.

## Что работает

- Каталог 17 площадок-кандидатов, исключение площадок из продаж.
- Ручные котировки и атомарный CSV-импорт; время, источник, способ вывода, комиссии.
- Раздельное сравнение мгновенных продаж и цен выставления, история и график.
- Цены старше суток, Steam, исключенные площадки и непроверенные способы вывода не рекомендуются.
- Партии по владельцам, завершенные продажи, фактические переводы, остатки и долг.
- 15% от фактически полученных после вывода денег — тебе, оставшаяся сумма — владельцу.
  Расчет в копейках, доля округляется до копейки, остаток достается владельцу.
- Защита от продажи лишних кейсов и выплат сверх долга, включая одновременные запросы.

Все суммы в RUB. Криптовалютные выплаты записываются в рублевом эквиваленте после
фактической конвертации. Не складывай USDT и рубли без пересчета. Прогноз:
`(цена × количество × (1 − комиссия продажи) × (1 − комиссия вывода)) − фиксированная комиссия`.
Фиксированная комиссия применяется один раз за весь вывод; условия конкретного сайта могут отличаться.
Это оценка по введенным данным: объем заявок, сроки продажи, лимиты вывода и проскальзывание не учитываются.

## Автоматический сбор

`python3 app.py` автоматически запускает фоновый сборщик вместе с интерфейсом.
Первый запрос выполняется при запуске, следующие — каждые 15 минут. Кнопка
«Проверить обновление» будит сборщик, сохраняя интервалы запросов. Срок следующей
попытки хранится в SQLite: перезапуск и несколько процессов не обходят ограничение.
При ошибках пауза увеличивается до 6 часов. Последняя успешная цена остается с ее
исходным временем; ошибок с фиктивной ценой 0 нет.

Подключены публичные API:

| Площадка | Данные | Проверка в текущей среде |
| --- | --- | --- |
| Market.CSGO | Цена предложения Danger Zone Case в RUB | Живой запрос успешен |
| Steam Community Market | Минимальная цена предложения в RUB | Живой запрос успешен; без денежного вывода |
| Skinport | Минимальная цена предложения в USD | Источник ответил HTTP 403; живой результат не подтвержден |

Сбор не требует ключей. Разрешенные домены: `market.csgo.com`, `steamcommunity.com`,
`api.skinport.com`. HTTPS-проверка сертификатов включена; обход защиты сайтов не используется.
Автосбор добавляет каждую успешную котировку в историю и график. График фильтруется
по валюте, рубли и доллары не смешиваются. Отмеченное время — получение API-ответа,
а не подтвержденное время обновления цены на стороне площадки.

Цены хранятся независимо от условий вывода. В интерфейсе задай комиссии, способ
вывода и при необходимости курс USD/RUB один раз для каждой площадки. После этого
расчет выручки использует свежую автоматическую цену. Курс конвертации и комиссии
обновляются вручную; до их подтверждения источник не включается в рекомендации.
У каждой площадки хранится один активный набор условий вывода. Для сравнения
нескольких способов по одной площадке можно добавлять ручные котировки.

Отдельный запуск без веб-интерфейса:

```sh
python3 collect.py --once  # Один цикл; exit 1, если источник в состоянии ошибки
python3 collect.py         # Постоянное обновление; Ctrl+C для остановки
```

Не нужно запускать отдельный сборщик вместе с app.py. Исключение площадки запрещает
ее рекомендации и продажи, но сохраняет сбор цен для наблюдения.

## Ограничения

Каталог 17 площадок не является проверенным списком всех популярных сервисов.
Автосбор реализован для трех источников выше, остальные 14 пока доступны только
для ручных котировок и CSV. Skinport требует разрешения проблемы доступа со стороны
сервиса; повтор после изменения доступа произойдет автоматически по расписанию.
Доступность вывода в РФ, комиссии, лимиты, объем спроса и актуальность сайтов
требуют отдельной проверки. Нет торговли, подключения Steam, кошельков или отправки
денег. Нет статусов выставления, отмены/редактирования операций; вводятся только
завершенные продажи и выплаты.

CSV: `market,price_rub,sale_fee,withdrawal_fee,fixed_fee_rub,method,verified,kind,observed_at,source`.
Названия площадок как в каталоге; `verified`: 0/1, `kind`: instant/listing.
`observed_at`: ISO 8601 с часовым поясом; если пусто — время импорта.
`source`: ссылка/описание источника и использованного валютного курса.

## Проверка и хранение

```sh
python3 -m unittest discover -s tests -v
```

База: `.data/cases.sqlite3`, путь можно переопределить `CASEPARSER_DB`, порт — `PORT`.
Храни резервную копию базы вне checkout; для согласованной копии используй SQLite backup
либо копируй файл после остановки сервера. Данные не отправляются внешним сервисам.
Каждый cloud task уже изолирован; используй существующий checkout, отдельный worktree не нужен.
